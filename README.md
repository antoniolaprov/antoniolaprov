Hoje meu foco é **ML aplicado a dados tabulares e séries temporais**: avaliar um
modelo sem vazar o futuro, saber se ele ganha de um baseline simples e mantê-lo
funcionando quando o dado muda.

<summary><b>O que tem no AgroClima</b></summary>

- Alvo e normais climáticas calculados só com anos anteriores, sem vazamento
- Validação temporal (rolling origin), skill contra a tendência com IC 95% por bootstrap de anos
- Baselines, ablações e previsão antecipada com 1/3 e 2/3 do ciclo observado
- LightGBM com SHAP, tracking no MLflow e model card para o Hugging Face
- Retreino no Airflow só quando o dado muda, com portão de promoção
- Pipeline Bronze/Silver/Gold com dbt + DuckDB, dashboard Streamlit e site em Next.js

</details>
